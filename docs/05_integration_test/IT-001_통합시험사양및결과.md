# 통합 시험 사양 및 결과 — 전자식 차일드락 제어 SW

| 항목 | 내용 |
|---|---|
| 문서 ID | IT-001 |
| 베이스라인 | BL-INT-1.0 (초안) |
| 대상 | `child_lock` 전체 (web.server ↔ driver_request ↔ controller ↔ event_log ↔ status) |
| 상위 입력 | SWA-001 (인터페이스·동적 구조), SWR-SPEC-001 |
| A-SPICE | SWE.5 SW 통합 및 통합 시험 |
| 시험 코드 | `tests/integration/` |
| 시험 환경 | Windows 11, Python 3.12.10, pytest 9.2.0, 실제 HTTP 서버(임시 포트), 별도 프로세스 기동 |

## 1. 통합 전략

모듈 단위 시험(UT-001)을 통과한 11개 모듈을 SWA-001의 의존 방향 그대로 한 번에 통합한다(빅뱅 아님: 단위 시험에서 각 모듈 인터페이스를 이미 검증). 통합 시험은 모듈 경계를 실제로 넘는 경로만 다룬다.

| 경계 | 검증 대상 | 시험 |
|---|---|---|
| HTTP ↔ App | 요청 본문 해석, 상태 코드, JSON 직렬화 | IT-01, 06, 07 |
| App ↔ driver_request ↔ controller | 명령 해석 결과 전달 (AD-05) | IT-02, 03 |
| controller ↔ event_log (콜백) | 결정·보조 이벤트 기록 순서 | IT-03 |
| controller 내부 상태 ↔ 여러 주기 | 래치, 가드, 지연 | IT-04, 05 |
| 프로세스 경계 | 휘발성, 파일 미생성 | IT-08 |
| replay ↔ 전체 | 결정론 | IT-09 |
| 시간 예산 | 평가 1회 처리 시간 | IT-10 |

## 4. 결함 및 잔여 문제

통합 시험 중 발견한 결함 없음.

| ID | 내용 | 처리 |
|---|---|---|
| IT-N-01 | `--tick` 모드는 서버 시계를 쓰므로, 클라이언트가 보낸 `timestamp_s`와 서버 시계가 다르면 지연 판정이 어긋난다 | 시뮬레이터 사용 안내에 기록. 결정론 시험은 tick 없이 `now_s`를 명시해 수행 (AD-04) |
| IT-N-02 | IT-10 시간 측정은 PC 성능에 의존한다 | 기준(1 ms)이 주기(50 ms)보다 50배 작아 여유가 큼 |
