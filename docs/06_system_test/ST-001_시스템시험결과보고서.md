## 4. 미검증 범위와 잔여 문제

- **Web 화면 확인 2건 미수행** (STC-F-073, 074): 시험자가 브라우저로 확인해야 한다.
- **실시간 응답 시간**: 100 ms(SR-003), 300 ms(SR-001) 요구는 가상 시계에서 평가 주기 수로 확인했다. 실시간 측정은 `max_response_ms` 단계와 IT-10(평가 1회 평균 1 ms 미만)으로 보완했으며, 실제 50 ms 주기 스케줄링은 PC/SIL 범위 밖이다.
- **OEM 미회신 질의 11건** (Q-01~Q-11, `SWR-004_OEM질의및검토기록.md`). 특히 Q-01(우선순위), Q-02(override), Q-11(지연 충돌 신호)은 안전에 직접 영향을 준다.
- 시험 케이스의 `확인 필요` 시트 15건 중 요구사항에 반영되지 않은 항목은 OEM 질의와 겹치거나(Q-01, Q-03, Q-07, Q-11) 시험 해석 가정(시각 경계 값 선택 등)이다.
- HIL, 실차, 타깃 ECU, 실제 CAN 타이밍은 범위 밖이다 (OEM 사양서 1.3절).
