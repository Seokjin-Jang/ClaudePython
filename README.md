# ClaudePython

AI(Claude)를 활용해 작성한 파이썬 코드 모음입니다.

## 개요

이 저장소는 AI 코딩 도구인 Claude Code와 함께 만든 파이썬 예제와 스크립트를 모아 둔 곳입니다.
각 코드는 AI의 도움을 받아 작성했으며, 실행 방법과 설명을 함께 정리합니다.

## 요구 사항

- Python 3.10 이상
- Git

## 시작하기

### 1. 저장소 복제

```bash
git clone https://github.com/Seokjin-Jang/ClaudePython.git
cd ClaudePython
```

### 2. 가상 환경 만들기 (권장)

Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 패키지 설치

`requirements.txt`가 있는 경우:

```bash
pip install -r requirements.txt
```

## 사용 방법

각 스크립트는 다음과 같이 실행합니다.

```bash
python <파일명>.py
```
